# CERPEN — Desenvolvimento Web

Portfólio profissional desenvolvido com React, Vite, Framer Motion e Lucide Icons.

## Executar localmente
```bash
npm install
npm run dev
```

## Publicar na Vercel
Importe este repositório na Vercel. Framework: **Vite**. Build: `npm run build`. Diretório de saída: `dist`.

## Personalizar
- Contatos: edite `contact` em `src/App.jsx` (WhatsApp com DDI e DDD, e-mail e Instagram).
- Projetos: substitua os exemplos no array `projects` e a arte demonstrativa por imagens e links reais.
- Serviços: altere o array `services`.
- Estilo e cores: `src/style.css`.

Os projetos exibidos são placeholders ilustrativos e não representam clientes reais. O botão de orçamento usa e-mail genérico até a configuração de um contato real.
